# 花朵大作战 · Flower Catcher

一个 HTML5 Canvas 接花小游戏：电脑 / 平板 / 手机打开即玩，**无需构建、无需安装依赖**。游戏本体是纯静态页面，只有排行榜接入了托管云数据库（Serverless，无需自己搭服务器）。

## 开始玩

- 本地：双击 `index.html` 直接用浏览器打开（`file://` 也能正常播放音乐和音效）
- 在线试玩：https://wbapp-yudaw7fmiebs5k4zewgq8m.app.workbuddy.host/?sharecode=6XOBM3KVKO
- GitHub Pages 启用后，也可以用 `https://<用户名>.github.io/flower-catch/` 打开

操作：鼠标移动 / 手指拖动 / `← →` 或 `A D` 控制底部角色；`ESC` 或右上角暂停按钮可呼出暂停界面（继续游戏 / 重新开始 / 返回主页面）。

右上角两颗声音按钮**互相独立**：音符键只管背景音乐，喇叭键只管接花、爆炸、死亡等音效。

## 玩法

- 接到花朵加分，连击有倍率；接到炸弹扣 1 点生命，共 3 点
- 第 3 关起会掉落回血爱心
- **闯关模式**：5 关独立计分（300 / 600 / 900 / 1200 / 1500），逐关解锁分值更高的新花和不同背景主题。进度存在浏览器 `localStorage`，关掉网页再打开还在；开始界面右下角可重置进度。
- **无尽模式**：通关第 5 关后解锁。按分数分档，越往后掉得越快、炸弹越多、越容易成排出现；全程有随机回血道具，记录历史最高分。
- **无尽模式排行榜（全服共享）**：榜单存在云端数据库，所有打开这个网址的玩家看到同一份排名，换设备 / 换人都能互相看到。首页可设置上榜 ID（默认 `童琴99`）；无尽模式破纪录即实时上榜，阵亡结算、暂停返回首页、直接关网页都不会丢，结算面板里还能改 ID。不同玩家用了同一个 ID 时按主机指纹分配编号，排行榜里以灰色 `#1/#2` 区分。**没有登录**，所以理论上可以刷榜。
- **自己那条会高亮**：判定依据是本机的主机指纹，所以同一台设备换过几个 ID 上榜，这几个 ID 都会高亮（橙色渐变底 + 左侧色条 + `你` 徽章），换设备或清过浏览器数据则认不出来。打开排行榜时会自动把自己那一行滚到可视区中间，成绩排在后面也能一眼找到。
- **自适应缩放**：玩家角色、投掷者、花朵/炸弹/爱心及碰撞判定共用同一个缩放系数，桌面与宽屏为 100%（完全不变），手机竖屏约 60%，让窄屏也有足够的躲避空间；视觉与判定始终同步，不会出现「看着小了判定还大」。
- **掉落节奏补偿**：投掷者的脚底位置由 HUD 的实际下沿决定（见下条），掉落起点因此比早期版本更靠下、下落距离更短。初速与重力按剩余距离同比放慢（桌面约 0.84×、手机竖屏约 0.70×），把反应时间补回原来的约 1.48 秒；生成密度、角色速度与难度曲线都不变。所以「移动端不比电脑难」这个不变量在任何屏幕上都成立。
- **投掷者不被 HUD 压住**：她的脚底 = max(原位, HUD 下沿 + 角色可视高 + 8px)，HUD 下沿直接量 DOM（宽屏单行 / 窄屏两行都自动适配），量不到时用经验值兜底。窄屏两行 HUD 更高，她自然被推得更低。
- **通关结算演出（闯关模式）**：过关瞬间玩家锁定、场上道具清空。投掷者先在**她自己那一层高度水平**跑出画面（不斜着走、不往下掉），画面外才换到玩家所在的地面高度，再从**同侧边缘水平**走回来，走到玩家身边停下（贴住不穿过去）；两人一起换成 `结算画面` 的 9 帧合影（整段 5 秒，一帧约 0.56 秒），播完才弹出「下一关」面板。左半边 → 向左跑出再从左边走回；右半边则镜像。
- **撒花跟着丢花走**：撒花动画的一个循环长度 = 当前关卡的生成间隔（第 1 关约 1.15 秒，越往后间隔越短、她也撒得越快），每次丢花都从撒花第一帧重新开始，所以永远是「撒完就扔」，不会出现撒好两轮才丢一朵的错位。

## 目录结构

| 路径 | 作用 |
| --- | --- |
| `index.html` | 页面结构、HUD、开始 / 暂停 / 结算面板、防缓存脚本加载 |
| `css/style.css` | 自适应布局（按画面宽度等比缩放，适配手机竖屏到超宽屏） |
| `js/config.js` | **所有参数与素材入口**：难度、花朵、背景主题、BGM 播放列表 |
| `js/sprites.js` | Canvas 矢量绘制、玩家与投掷者的 PNG 帧动画 |
| `js/game.js` | 主逻辑、状态机、碰撞判定、关卡、存档、声音、通关演出 |
| `js/cloud-board.js` | 云服务 SDK 初始化、公开配置、全服排行榜读写（SDK 由 CDN `<script>` 引入） |
| `assets/player/` | 玩家（捡花的人）动作帧序列：`walk-left` / `walk-right` / `catch` / `hurt` / `dead` |
| `assets/thrower/` | 投掷者（撒花的人）动作帧序列：`sprinkle`（8 帧）/ `walk-left`（4 帧）/ `walk-right`（4 帧）/ `finish`（9 帧合影） |
| `assets/bgm/` | 4 首背景音乐 |
| `tools/` | 三个自检脚本 |

## 换素材 / 调难度

主要改 `js/config.js`，改完刷新即可生效（脚本加载带时间戳，不会被浏览器缓存）：

- `IMAGE_ASSETS`：把 `src` 改成自己的图片路径，留 `null` 就用内置矢量绘制
- `PLAYER_ANIMS`：玩家动作帧序列放在 `assets/player/<动作>/1.png …`；`displaySize` 调角色大小
- `THROWER_ANIMS`：投掷者动作帧序列放在 `assets/thrower/<动作>/1.png …`。`displaySize` 调大小、`anchorY` 把脚对齐脚底线、`topPad` 是源图顶部留白比例（算站位"露头高度"要用它）、`finishWidth` 调合影大小。速度有三种写法：`syncToSpawn: true`（撒花：一个循环 = 一次丢花，自动跟随关卡生成间隔）、`durationSec: 5`（合影：整段固定 5 秒）、`fps`（走路：固定帧率）
- `FINALE`：通关演出的走路速度 `walkSpeed`、两人"碰到"的距离 `meetGap`、出画后停顿 `pauseTime`、合影播完停留 `screenHold`
- `LEVELS` / `ENDLESS`：闯关与无尽的难度曲线
- `FLOWERS`：5 种花的分值与配色
- `THEMES`：5 套背景主题（晴天草原 / 星夜 / 樱花林 / 黄昏高原 / 冰雪世界）
- `BGM.playlist`：背景音乐**顺序轮播**列表，改数组即可换曲或调顺序；`volume` 调音量、`fadeMs` 调淡入淡出时长

音效（接花 / 爆炸 / 死亡 / 过关）由 WebAudio 实时合成，没有音频文件；BGM 用 `<audio>` 元素播放，以兼容 `file://` 直接打开。

## 自检脚本

需要 Node.js，在项目根目录执行：

```bash
node tools/smoke.js       # DOM id / 素材文件 / 帧动画 / 关卡表静态自检
node tools/headless.js    # 无头跑真实主循环：关卡解锁、暂停、BGM 轮播、爱心回血等
node tools/pace.js 1 60   # 用真实参数跑第 1 关 60 秒，观察分数与进度节奏
```

## 说明

- 关卡解锁进度、玩家 ID、主机指纹仍只存在玩家自己的浏览器 `localStorage`；排行榜成绩存在云端数据库（`public.scores`）。没有账号系统、不收集身份信息。
- 排行榜通过 CDN 引入 SDK 并直连云端，**只有发布后的网址能用**：本地 `file://` 打开时 Origin 不匹配，页面会显示「排行榜暂时加载失败」，不会静默退回本地数据；CDN 不可达时同理。
- 提交走数据库函数 `submit_score`：服务端校验输入、同一玩家只留最高分且只能升不能降；客户端没有直接改表的权限，改不了别人的成绩。榜单读取是公开只读。
- 开始界面右下角的小字「清除分数记录」带二次确认：清本机最高分并只删**自己**在云端那条成绩，不影响其他玩家，也不影响关卡解锁进度和玩家 ID。
- `assets/bgm/` 下的第三方音乐素材请按各自授权条款使用；换成自己的曲子只需改 `BGM.playlist`。
