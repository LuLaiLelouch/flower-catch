# 花朵大作战 · Flower Catcher

一个纯静态的 HTML5 Canvas 接花小游戏：电脑 / 平板 / 手机打开即玩，**无需构建、无需安装依赖、无需后端**。

## 开始玩

- 本地：双击 `index.html` 直接用浏览器打开（`file://` 也能正常播放音乐和音效）
- 在线试玩：https://wbapp-yudaw7fmiebs5k4zewgq8m.app.workbuddy.host/?sharecode=6XOBM3KVKO
- GitHub Pages 启用后，也可以用 `https://<用户名>.github.io/flower-catch/` 打开

操作：鼠标移动 / 手指拖动 / `← →` 或 `A D` 控制底部角色；`ESC` 或右上角暂停按钮可呼出暂停界面（继续游戏 / 重新开始 / 返回主页面）。

右上角两颗声音按钮**互相独立**：音符键只管背景音乐，喇叭键只管接花、爆炸、死亡等音效。

## 玩法

- 接到花朵加分，连击有倍率；接到炸弹扣 1 点生命，共 3 点
- 第 3 关起会掉落回血爱心
- **闯关模式**：5 关独立计分（300 / 600 / 900 / 1200 / 1500），逐关解锁分值更高的新花和不同背景主题。进度存在浏览器 `localStorage`，关掉网页再打开还在；开始界面右下角可重置进度。
- **无尽模式**：通关第 5 关后解锁。按分数分档，越往后掉得越快、炸弹越多、越容易成排出现；全程有随机回血道具，记录历史最高分。

## 目录结构

| 路径 | 作用 |
| --- | --- |
| `index.html` | 页面结构、HUD、开始 / 暂停 / 结算面板、防缓存脚本加载 |
| `css/style.css` | 自适应布局（按画面宽度等比缩放，适配手机竖屏到超宽屏） |
| `js/config.js` | **所有参数与素材入口**：难度、花朵、背景主题、BGM 播放列表 |
| `js/sprites.js` | Canvas 矢量绘制与玩家 PNG 帧动画 |
| `js/game.js` | 主逻辑、状态机、碰撞判定、关卡、存档、声音 |
| `assets/` | 图片、玩家动作帧序列、4 首背景音乐 |
| `tools/` | 三个自检脚本 |

## 换素材 / 调难度

主要改 `js/config.js`，改完刷新即可生效（脚本加载带时间戳，不会被浏览器缓存）：

- `IMAGE_ASSETS`：把 `src` 改成自己的图片路径，留 `null` 就用内置矢量绘制
- `PLAYER_ANIMS`：玩家动作帧序列放在 `assets/player/<动作>/1.png …`；`displaySize` 调角色大小
- `LEVELS` / `ENDLESS`：闯关与无尽的难度曲线
- `FLOWERS`：5 种花的分值与配色
- `THEMES`：5 套背景主题（晴天草原 / 星夜 / 樱花林 / 黄昏高原 / 冰雪世界）
- `BGM.playlist`：背景音乐**顺序轮播**列表，改数组即可换曲或调顺序；`volume` 调音量、`fadeMs` 调淡入淡出时长

音效（接花 / 爆炸 / 死亡 / 过关）由 WebAudio 实时合成，没有音频文件；BGM 用 `<audio>` 元素播放，以兼容 `file://` 直接打开。

## 自检脚本

需要 Node.js，在项目根目录执行：

```bash
node tools/smoke.js       # DOM id / 素材文件 / 帧动画 / 关卡表静态自检
node tools/headless.js    # 无头跑真实主循环：关卡解锁、暂停、BGM 轮播、爱心回血等
node tools/pace.js 1 60   # 用真实参数跑第 1 关 60 秒，观察分数与进度节奏
```

## 说明

- 纯前端项目：进度只存在玩家自己的浏览器里，没有服务端、没有账号系统、不收集任何数据。
- `assets/bgm/` 下的第三方音乐素材请按各自授权条款使用；换成自己的曲子只需改 `BGM.playlist`。
